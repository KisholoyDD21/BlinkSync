# Security policy

BlinkSync handles accepted source code and a GitHub access token. Please do not report suspected vulnerabilities in a public issue.

If private vulnerability reporting is enabled, use GitHub's **Report a vulnerability** option in the repository's Security tab. Otherwise, contact the maintainer through their GitHub profile. Include the affected version or commit, impact, and concise reproduction details. Do not include real access tokens, private source code, or personal data in the report.

This project is an engineering scaffold; the LeetCode integration relies on undocumented site behavior and has not been declared production-ready.
