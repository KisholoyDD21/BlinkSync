Privacy Policy

Effective Date: November 17, 2026 · Local-First Architecture
Zero Telemetry Guarantee: BlinkSync does not operate any analytics server, tracking database, or remote logging service. All sync operations occur directly between your browser and the GitHub API.

1. Overview & Data Ownership

BlinkSync ("the extension", "we") is a developer productivity tool designed to synchronize your verified LeetCode accepted solutions to a GitHub repository under your control. We believe in total data sovereignty: your code, tokens, and solution history belong solely to you.

2. What Information is Handled

  • LeetCode Submissions: When you submit a solution on LeetCode, the extension verifies the verdict through LeetCode's public GraphQL endpoint. It extracts the submitted source code, runtime, memory metrics, and question metadata.
  • GitHub Personal Access Tokens (PAT): Your PAT is stored in chrome.storage.session by default. Session storage is isolated to the extension process and automatically cleared upon closing your browser. Tokens are never transmitted to third parties or logged.
  • Local Cache & Queue: Your synchronization ledger and retry queue are maintained strictly on your machine using standard browser IndexedDB and chrome.storage.local.

3. Network Communications

BlinkSync initiates HTTPS network calls exclusively to two origins:

  • https://leetcode.com/graphql — To verify submission status using your existing, authenticated browser session cookies.
  • https://api.github.com — To commit solution source code and problem documentation directly to your target repository using your provided token.

4. Optional Features & Consent

Automatic synchronization remains dormant until you review and check the explicit source transfer consent checkbox in the extension settings. By default, full problem statements are excluded from your commits to respect proprietary LeetCode problem descriptions unless you explicitly opt in.

5. Revocation & Token Removal

You can revoke access at any time by clicking Clear Token in the BlinkSync extension popup or by deleting the Personal Access Token in your GitHub Settings. Uninstalling the extension immediately wipes all local storage and history.
