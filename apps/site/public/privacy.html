Privacy Policy

Draft — publish only after verifying it matches the released build.

BlinkSync processes LeetCode submission identifiers, source code, and problem metadata solely to synchronize accepted solutions to the GitHub repository selected by the user. The extension sends GitHub API requests directly from the user's browser. The full LeetCode problem statement is excluded from generated READMEs by default and is copied only when the user enables that optional setting. The extension does not operate an analytics or submission-storage backend.

A GitHub token is stored in chrome.storage.session and is accessible only to trusted extension contexts in this build. It is cleared when the browser session ends, the extension is reloaded, or the browser restarts. Repository settings and sync history remain in chrome.storage.local. Pending submission IDs and verified source payloads are kept in extension-origin IndexedDB.

LeetCode submission details are requested from leetcode.com using the user's existing signed-in browser session. Solution code and README content are sent to api.github.com only after the extension verifies the submission's Accepted status and the user has configured a destination repository.

No data is sold, used for advertising, or transmitted to BlinkSync-operated analytics services. GitHub and LeetCode process data under their own privacy policies and terms.

Users can disconnect by clearing the session token, pausing sync, or removing the extension. To revoke access, also revoke the GitHub token in GitHub settings.
