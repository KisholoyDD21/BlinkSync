01 / Verified Source

Fetches the actual accepted submission directly through LeetCode's GraphQL API instead of trusting whatever unverified code happens to be in your active editor.

02 / Atomic Git Commits

Your source code and beautifully formatted Markdown problem README are committed together in a single atomic Git commit using GitHub's Git Data API.

03 / Durable Local Queue

Local IndexedDB queue, SHA deduplication, contest-safe release, and offline retry logic guarantee that no accepted solution is ever dropped or lost.
